# DeepIP

> AI patent intelligence for IP professionals — invention capture, patentability
> assessment, drafting and drawings, AI review, prosecution, freedom-to-operate and
> invalidity search, and portfolio intelligence — delivered inside Microsoft Word,
> IP management systems, and the browser. DeepIP operates a remote, OAuth-protected
> Model Context Protocol server for agents. It publishes no OpenAPI, and its REST
> API reference is behind a login.

Generated by API Evangelist from probed public surface. DeepIP does not publish an
llms.txt of its own (https://www.deepip.ai/llms.txt returns 404).

## Agent surface

- [MCP endpoint](https://app.deepip.ai/mcp): Remote Model Context Protocol server.
  OAuth 2.0 authorization-code + PKCE (S256). Returns 401 MISSING_CREDENTIALS
  without a bearer token; the tool list requires an authenticated DeepIP tenant.
- [Protected resource metadata](https://app.deepip.ai/.well-known/oauth-protected-resource/mcp):
  RFC 9728. Names the resource and its authorization server. Resolves anonymously.
- [Authorization server metadata](https://app.deepip.ai/.well-known/oauth-authorization-server):
  RFC 8414. authorize/token/revoke endpoints under /mcp/. Resolves anonymously.
- [OpenID Connect discovery](https://auth.deepip.ai/.well-known/openid-configuration):
  Auth0 tenant used for end-user sign-in to the DeepIP application.

## Crawling and consent

- [app.deepip.ai/robots.txt](https://app.deepip.ai/robots.txt): Content-Signal
  search=yes, ai-train=no, use=reference. Disallows ClaudeBot, GPTBot, CCBot,
  Bytespider, Amazonbot, Applebot-Extended, Google-Extended, meta-externalagent.
  Do not crawl the application host. Authenticated MCP access is the supported path.
- [www.deepip.ai/robots.txt](https://www.deepip.ai/robots.txt): Allow all.
